# Amarula

Code name for CircleOS v1 — the first shipping version, built on OpenHarmony.

**What this is:** the single source of truth for CircleOS going forward. OS specs, product configs, Circle-specific components, and baked-in apps all live here.

**What this is not:** the old AOSP-based CircleOS. That work is archived; its concepts port here, its code does not.

**Status:** pre-v0.00001. Specs first, then code.

**Release naming:** code names follow fruits A–Z. v1 = Amarula.
